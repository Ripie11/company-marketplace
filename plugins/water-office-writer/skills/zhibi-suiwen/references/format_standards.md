# 党政机关公文格式标准摘要（GB/T 9704—2012）

> 本文件是 zhibi-suiwen 的格式参考规范。当用户要求"严格按党政公文标准"或样本中检测到疑似党政机关公文时，由 SKILL.md 按需加载。

## 一、字体与字号

| 要素 | 字体 | 字号 |
|------|------|------|
| 主标题（发文机关标志） | 方正小标宋简体（红色） | 不超过 22mm × 15mm |
| 标题（一级） | 黑体 | 三号（16pt） |
| 标题（二级） | 楷体_GB2312 | 三号（16pt） |
| 标题（三、四级） | 仿宋_GB2312 加粗 | 三号（16pt） |
| 正文 | 仿宋_GB2312 | 三号（16pt） |
| 页码 | 仿宋_GB2312 | 四号（14pt） |

## 二、段落格式

- **行距**：固定值 28 磅（部分场景用"1.5 倍行距"）。
- **首行缩进**：2 字符。
- **段前段后**：0（默认）。
- **段落对齐**：左对齐（两端对齐）。
- **段间距**：无（依靠行距控制）。

## 三、页面格式

- **纸张**：A4（210mm × 297mm）。
- **页边距**：上 37mm / 下 35mm / 左 28mm / 右 26mm（GB/T 9704—2012 标准）。
- **页码**：居中、四号半角阿拉伯数字、单页码居右、双页码居左；或统一居中。

## 四、标点符号

- 中文段落使用全角标点：，。；：？！""''【】
- 数字、英文使用半角：0-9, a-z, A-Z
- 数字与中文混排时，数字前后保留空格习惯（如"2026 年 9 月 10 日"）。

## 五、落款与成文日期

- **位置**：右下角，距正文 2-3 行。
- **格式**：领导姓名（不写职务）+ 日期（YYYY 年 M 月 D 日 或 YYYY-MM-DD）。
- **示例**：
  ```
                                          方  琳
                                       2026年9月10日
  ```
  或：
  ```
                                          深圳水务集团
                                       2026年9月10日
  ```

## 六、标题层级

公文标题层级不宜过多，建议最多三级：

```
一、XXX              （黑体三号）
（一）XXX            （楷体三号）
1. XXX                （仿宋三号加粗 / 黑体三号）
（1）XXX              （仿宋三号）
```

注意：阿拉伯数字编号与中文数字编号不混用。

## 七、常见公文文种格式要点

| 文种 | 特点 |
|------|------|
| 决议 | 标题"关于……的决议"；正文用"会议认为……""会议指出……""会议要求……" |
| 决定 | 标题"关于……的决定"；正文开门见山、目的明确 |
| 通知 | 标题"关于……的通知"；正文"主送机关 + 正文 + 结尾" |
| 通报 | 标题"关于……的通报"；正文含"情况 + 经验/教训 + 要求" |
| 报告 | 标题"关于……的报告"；正文"缘由 + 事项 + 结语" |
| 请示 | 一事一请；语气恳切；结尾用"妥否，请批示" |
| 批复 | 标题"关于……的批复"；正文"缘由 + 答复" |
| 函 | 标题"关于……的函"；语气谦和、得体 |
