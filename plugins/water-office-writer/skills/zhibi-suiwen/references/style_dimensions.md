# 风格提取的完整维度清单

> 本文件是 zhibi-suiwen 在阶段 A 中使用的检测维度清单。当需要扩展提取能力（如新增多语言、图片表格、附件等）时由 SKILL.md 按需加载。

## 一、格式维度（Format Dimensions）

### 1. 字体（Font Family）
- **检测方式**：从 docx 的 run.font.name / pptx 的占位符字体读取。
- **关注点**：是否使用公文标准字体（方正小标宋 / 黑体 / 楷体_GB2312 / 仿宋_GB2312）；是否使用非标准字体（宋体、微软雅黑等）。
- **特别注意**：相同字号下不同字体的视觉效果差异显著。

### 2. 字号（Font Size）
- **检测方式**：Pt 值；1 pt ≈ 0.353 mm。
- **公文标准字号**：
  - 初号：42pt
  - 小初：36pt
  - 一号：26pt
  - 小一：24pt
  - 二号：22pt
  - 小二：18pt
  - 三号：16pt（公文正文常用）
  - 小三：15pt
  - 四号：14pt
  - 小四：12pt
  - 五号：10.5pt

### 3. 颜色（Color）
- **检测方式**：RGB 十六进制值（如 #FF0000）。
- **公文特殊**：主标题（发文机关标志）通常为红色（#FF0000）。
- **其他**：正文通常为黑色（#000000）。

### 4. 字形（Style）
- 加粗（bold）、斜体（italic）、下划线（underline）。
- 公文中**几乎不使用斜体和下划线**。

### 5. 段落对齐（Alignment）
- 左对齐（left）、居中（center）、右对齐（right）、两端对齐（justify）。
- 公文中正文通常用**两端对齐**。

### 6. 行距（Line Spacing）
- 单倍行距、1.5 倍行距、固定值（pt）。
- 公文标准为**固定值 28 磅**。

### 7. 段前段后（Space Before / After）
- 单位：磅。
- 公文中通常为 0，依靠行距控制段间距。

### 8. 首行缩进（First Line Indent）
- 单位：字符或磅。
- 公文标准为**2 字符**。

### 9. 页面设置（Page Setup）
- 纸张大小（A4：A4 210mm × 297mm）。
- 页边距（mm）。
- 页码位置、字体、字号。
- 页眉页脚（机关名 / 文档名）。

### 10. 标题层级（Heading Levels）
- 标题字号、字体、加粗情况。
- 编号格式（一、（一）、1.、（1））。

## 二、语言维度（Linguistic Dimensions）

### 1. 句式偏好（Sentence Patterns）
- **短句 vs 长句**：公文偏好中等长度（30-60 字）。
- **句式特征**：
  - 排比："……，……，……，……"
  - 对仗："上下一心 / 内外联动"
  - 设问："为何要……？因为……"
  - 引用："习近平总书记强调……"

### 2. 用词偏好（Vocabulary）
- **四字词**：踔厉奋发、勇毅前行、真抓实干、久久为功、驰而不息、笃行不怠。
- **政策表述**：贯彻新发展理念、构建新发展格局、推动高质量发展。
- **动词偏好**：推进、深化、落实、强化、提升、聚力、聚焦、聚势。
- **副词偏好**：切实、深入、全面、扎实、有力。
- **名词偏好**：体系、机制、格局、篇章、蓝图。

### 3. 结构模式（Structure）
- **公文经典结构**：
  - 开篇：问候 + 会议主题 + 政策依据
  - 回顾：成绩 + 数据 + 表扬
  - 形势：机遇 + 挑战 + 分析
  - 任务：分点（"一要……二要……三要……"）
  - 收尾：号召 + 祝福

### 4. 称呼与署名（Salutation & Signature）
- **称呼**：同志们 / 各位代表 / 各位同仁 / 各位嘉宾。
- **署名**：领导姓名（不写职务）+ 日期。

### 5. 修辞手法（Rhetorical Devices）
- 比喻："把……比作……"
- 排比："A，B，C，D"
- 对比："过去……，现在……"
- 引用：经典语句、政策文件、领导人讲话。

### 6. 情感倾向（Sentiment）
- 公文情感偏正面、激励、鼓动。
- 避免负面词汇（除非必要的批评与自我批评）。

## 三、检测方法建议

| 维度 | 推荐工具 |
|------|----------|
| 字体 / 字号 / 颜色 | python-docx, python-pptx |
| 段落格式 | python-docx |
| 页面设置 | python-docx (sectPr) |
| 文本提取 | pdfplumber, python-pptx, python-docx |
| 高频词统计 | jieba + Counter |
| 句式识别 | 正则表达式 + 模式匹配 |
| 政策表述识别 | 关键词词典匹配 |

## 五、异常处理

- **样本过少**（< 3 份）：警告"样本不足，风格档案可能不稳定"，建议补充。
- **样本风格不一致**：识别为"领导文风多变"，建议分场景建模。
- **格式完全偏离标准**：提示用户"样本与公文标准差异较大"，建议复核。
- **加密 / 损坏文件**：跳过并提示用户检查源文件。
