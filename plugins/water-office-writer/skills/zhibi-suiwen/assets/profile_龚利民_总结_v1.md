## 二、结构范式

### A. 半年总结（要点式）

```
开场      同志们： + 半年整体形势概括
成效      5 条「一是……二是……」+ 具体数据
不足      3 条「一是……二是……三是」+ 问题+原因+影响
要求      7 条「（一）～（七）」，含政策依据+具体措施+责任单位
          例：（一）全力完成81亿元固投任务
              （二）推动科技创新与产业创新深度融合，加快发展水务新质生产力
              （三）想方设法拓展外部市场，全力实现海外市场新突破
              （四）深入谋划"十五五"时期重点工作
              （五）调整组织架构，以更好推动"十五五"规划的落实
              （六）进一步强化安全管理，为完成全年任务保驾护航
              （七）全面加强党的领导和党的建设，全面从严治党
结尾      附字数与时长标注（4710字，约25分钟）
```

### B. 年终总结（三大块）

```
标题    新形势 新优势 新突破                    ← 三词对仗
副标题  ——在集团年终工作总结大会上的讲话
落款    集团党委书记、董事长 龚利民
        （2026年2月11日）

一、2025及"十四五"工作回顾 —— 5 方面"新"变化
     （一）民生保障实现"新"提升
     （二）科技创新迸发"新"活力
     （三）市场拓展实现"新"突破
     （四）改革发展取得"新"成效
     （五）党建引领达到"新高度"
二、全面把握新形势与新优势
     （一）新形势（5 点）（二）新优势（4 方面）（三）奋斗方向
三、全力实现"十五五"高质量发展新突破
     （一）～（六）共 6 条
```

### 标志性手法

| 手法 | 例证 |
|------|------|
| **五「新」字体系** | 民生保障「新」提升 / 科技创新「新」活力 / 市场拓展「新」突破 / 改革发展「新」成效 / 党建引领「新」高度 |
| **直接引用批示** | 「伟中市长今年 1 月批示，要'科学、有序、积极推进'」|

| **判断句** | 「科技转型不是选择题，而是生存题」|
| **转型句式** | 「从'传统水务企业'向'科技型企业'转变」|
| **结尾标注** | （字数10557字，约50分钟）|

## 三、语言特征

### 语气标签

1. **宏观政治高度** —— 从国家战略、城市定位切入
   > 「时代浪潮和国家政策下，不进则退，慢进亦退；慢走一步，差之千里。」
2. **强号召力** —— 结尾有力收束
   > 「锐始者必图其终，成功者先计于始。」
3. **战略化表达** —— 双主业/双市场/新质生产力/出海战略
4. **成语密度高** —— 迎难而上、苦干实干、善作善成、立柱架梁

### 高频词库

| 类别 | 词汇 |
|------|------|
| 四字词 | 迎难而上、真抓实干、善作善成、苦干实干、敢打硬仗、能打胜仗、立柱架梁、砥砺奋进 |
| 比喻 | 压舱石、桥头堡、颗粒归仓、应纳尽纳、拔钉清障、钉钉子精神 |
| 政治语 | 新质生产力、高质量发展、国内国际双循环、全国统一大市场、两个确立/两个维护 |
| **战略语** | 千亿级国内国际一流水务企业、双主业双市场、AI赋能、出海战略、水鸿生态、1+17+N党建品牌矩阵、深水云脑、深小水AI智能体、千家万户水管家、两化两力两集中 |
| 动词 | 锚定、聚焦、统筹、压实、攻坚、深化、强化 |
| 副词 | 坚决、切实、持续、全力、不断 |

### 金句（摘要，完整 33 条见 `voice_龚利民.md` §三）

**战略判断（破题定调）**
- 「科技转型不是选择题，而是生存题」
- 「不进则退，慢进亦退；慢走一步，差之千里」
- 「技术的价值，不在于算法多深奥，而在于能否回应群众所盼，能否解决民生所需」
- 「从"多点突破"迈向"系统繁荣"」

**动员号召（收尾起势）**
- 「锐始者必图其终，成功者先计于始」
- 「上坡路难走，力行则将至；顶风船难开，笃志则必达」
- 「自主创新，生态为要；数智水务，合作致远」

**民生价值 / 转型路径**
- 「以厂节约、以网控漏、以智赋能」
- 「从"用户发现"到"系统发现"、从"事后补救"到"事前干预"的服务跃升」
- 「年节水量达1.24亿立方米，约等于8.6个西湖的蓄水量」

**开放合作（致辞专属）**
- 「百川奔涌，汇聚成海」
- 「科技创新的春天再次来临」

**呈报谦敬（baogao 专属）**
- 「专此报告。」

> ⚠️ **金句密度红线**：总结 4500–5500 字 → 3–5 处；致辞 800–1600 字 → 1–2 处；呈报 3000–5000 字 → 0–1 处。过密=通篇口号。

## 五、与方琳的关键差异（防串台对照表）

| 维度 | 龚利民（董事长）| 方琳（总裁）|
|------|------|------|
| **正文字号** | 小二 **18pt** | 三号 **16pt** |
| **首行缩进** | 1.28cm | 1.13cm |
| **页边距** | 上3.7 下3.5 左2.6 右2.6 | 上3.7 下3.5 左2.8 右2.6 |
| **半年结构** | 开场 + 5条「是」+ 3条不足 + 7条「（一）～（七）」| 成效(9条) → 压力(3条) → 关注(4条) → 加油努力(5条) |
| **年终结构** | 三大块 + 五「新」| 12字四部分：实绩 / 形势 / 保底攀高 / 讲政治守规矩 |
| **标题风格** | 三词对仗（新形势 新优势 新突破）| 四字对仗两行（凝心聚力 真抓实干 / 奋力实现…）|
| **语气落点** | 号召、动员、方向、格言 | 自省、差距、压力、温情 |
| **人称** | 极少用「我」 | 常用「我」|
| **术语偏好** | 政策战略术语 | 商业资本术语（REITs、并购、上市）|
| **国际内容** | 大量国际对标与全球数据 | 较少，以国内经营数据为主 |
| **四字词密度** | **高**（迎难而上、善作善成、立柱架梁）| **低**（更接近现代经营语体）|
| **金句腔调** | 古语格言、对仗口号、判断句（「锐始者必图其终」）| 生活化比喻、三"如"排比、温情收束（安全是"1"）|
| **开篇** | 国家战略 → 城市定位 → 集团 | 承接上级/董事长发言 → 直接进实绩 |
| **章节标题** | 「新」字体系（新提升/新活力/新突破）| 双字词（成效/压力/关注）/ 数字＋关键词（12字四部分）|
| **数据风格** | 国际对标 + 规模排名 | 经营财务 + 精确到小数 2 位 |

> **一句话判断法（双向）**：龚董稿若无一路四字词、无战略口号、无国际对标 → 不像龚董；方琳稿若无一处数字、无一处自省、收尾还引了古文 → 不是方琳说的。
