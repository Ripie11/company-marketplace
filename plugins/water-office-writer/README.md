# 文秘专员（Secretary Specialist）

面向深圳水务集团综合办公室的公文写作专家：学习集团领导讲话风格，生成格式规范、语气贴合的总结报告、年终报告、会议致辞与呈报材料。

## 类型

Agent 型（单个 AI 专家）

## 功能

| 能力 | 说明 |
|------|------|
| **领导风格建模** | 从领导历次讲话/报告中提取**格式维度**（字体、字号、行距、缩进、页边距）与**语言维度**（语气画像、句式范式、金句库、词汇分层、禁用清单），构建可复用风格档案 + 领导专属语言手册 `voice_<领导>.md`。已内置**龚利民（董事长）**、**方琳（总裁）**两套 |
| **风格化报告生成** | 按指定领导风格撰写半年工作总结、年终报告、会议致辞、对外汇报等公文，做到"格式同源、语气同调、结构同律、金句同库" |
| **三文种分道** | `--doc-type` 一键切换互斥模板：`report`（总结/汇报）、`speech`（致辞/讲话，题注式版式）、`baogao`（呈报材料，主送机关顶格 + 单位落款） |
| **公文版式落地** | 输出符合党政机关公文格式的 Word 文档：主标题方正小标宋简体、一级标题黑体、条款引语楷体、正文仿宋_GB2312，固定行距、首行缩进 2 字符、A4 标准页边距 |
| **金句与语气复刻** | 加载领导专属 `voice_<领导>.md`，按文种选句式、按密度红线嵌金句（总结 3–5 处 / 致辞 1–2 处 / 呈报 0–1 处）、按词汇层遣词，杜绝"通用公文腔"与跨领导串台 |
| **知识库检索** | 通过乐享知识库检索集团历史讲话、工作总结、专题汇报素材，为写作提供事实依据与表述参考 |
| **知识库治理** | 文档入库四层闭环（classify / intake / kbsync / guardrails）：智能分类、dry-run 接入、乐享同步、未授权拒写 |
| **合规自检** | 生成后逐项复检字体、字号、缩进、称呼语、落款 + 金句密度与语气一致性，输出自检清单 |

## 内置风格档案

| 领导 | 版式档案 | 语言手册 | 版式要点 |
|------|----------|----------|----------|
| 龚利民（董事长） | `assets/profile_龚利民_总结_v1.yaml` / `.md`，另有致辞、呈报文种专属档案 | `assets/voice_龚利民.md` | 正文小二 18pt，首行缩进 1.28cm |
| 方琳（总裁） | `assets/profile_方琳_总结_v1.yaml` / `.md` | `assets/voice_方琳.md` | 正文三号 16pt，首行缩进 1.13cm |

> 两位领导版式与语言风格**不同源**，生成时务必按任务指定的领导分别处理，切勿混用。
>
> 语言维度的**唯一权威**是 `voice_<领导>.md`（档案中的 `linguistic` 块仅为摘要）；两者冲突时以语言手册为准。

## 使用示例

- 根据龚董风格，生成2026年上半年工作总结报告
- 以方琳总的口吻起草一份年终总结讲话稿
- 从乐享知识库检索集团历史讲话素材，整理成可复用的表述库
- 从知识库里再丰富一下领导的金句库

## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/water-office-writer/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/water-office-writer/
```

## 打包分享

```bash
zip -r water-office-writer.zip water-office-writer/
```

## 新手上路

第一次用请先看 [`USER_GUIDE.md`](./USER_GUIDE.md) — 包含能力清单、5 个 prompt 模板、能力边界与红线、Pre-flight Checklist。读完即可在 30 分钟内产出第一篇风格化公文。

详细的能力定义见 `/agents/water-office-writer.md`（专家身份与工作流）；`/skills/` 下分两个技能各自的 SKILL.md 描述完整能力。

## 三副本一致性

本专家包的两个技能各存在三处副本（插件包 / 项目级 skill / 专家分发包），插件外壳另存两处。
改动任一副本后请跑：

```bash
python skills/zhibi-suiwen/scripts/sync_copies.py --check
```

工具按 `SKILLS` 注册表同时管辖 `zhibi-suiwen` 与 `knowledge-base-organizer` 两个技能
（**新增技能必须登记**，否则漂移不会被发现）。用法与跨副本版本分叉台账（`TAKE_FROM`）
见脚本 docstring 与 `skills/zhibi-suiwen/selftest/README.md`。

> 领导称谓以**总裁方琳**为准（2026-09-14 确认）；「执行总裁」为历史误称，仅在
> `knowledge-base-organizer` 的归档目录别名与迁移映射中保留，用于兼容已归档素材。
