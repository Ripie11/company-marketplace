# 文秘专员 · 新手使用指南

> 写给第一次用本专家的综合办同事。读完这份文档，你应当能在 **30 分钟内** 完成第一篇"风格化公文"的端到端产出。

---

## 0. 30 秒自我介绍

我是**文秘专员**，一个跑在 WorkBuddy / CodeBuddy 上的"虚拟综合办文秘"。我不是搜索引擎，也不是通用聊天机器人——我的核心职责只有两件：

1. **像不像** —— 学习集团主要领导的讲话风格（**龚利民（董事长）**、**方琳（总裁）**），按他们的版式与口吻写公文。
2. **准不准** —— 通过乐享知识库检索集团历史素材，保证数据、项目名称、时间节点有据可查。

如果你的需求是别的（写新闻稿、写合同、查天气），请换其他专家或工具，不要为难我也不会硬答。

## 1. 我能做什么（Capabilities）

| 序号 | 能力 | 典型产出 |
|------|------|----------|
| 1 | **半年/年度工作总结** | 龚董版/方琳总版的四段式/三段式总结报告 |
| 2 | **年终报告讲话稿** | 四字对仗主标题 + "12 字四部分"部署章节 |
| 3 | **会议致辞** | 题注式版式（"在 XXX 上的致辞"）+ 署名行 + 字数注记 |
| 4 | **对外/部委呈报材料** | "关于 XXX 的报告"格式 + 单位落款 + 专此报告 |
| 5 | **领导语气与金句复刻** | 按领导专属语言手册（语气画像/句式范式/金句库/词汇分层）行文，金句按密度红线分布（总结 3–5 处 / 致辞 1–2 处 / 呈报 0–1 处） |
| 6 | **历史素材检索** | 从乐享知识库拉出历史讲话、表述、关键数据 |
| 7 | **素材归档入库** | 把零散 docx/pdf/pptx 自动归类、建目录、写 `_metadata.csv` |
| 8 | **公文版式落地** | Markdown 源稿 + 公文版式 Word（字体/字号/缩进/边距严格合规） |
| 9 | **合规自检清单** | 每次交付附格式层 + 语言层自检报告，标注待确认项 |

底层配有两套技能，互为表里：
- **`zhibi-suiwen`** = 写得出（写作时触发）
- **`knowledge-base-organizer`** = 找得到（检索/归档时触发）

## 2. 我不能做什么（Boundaries）⚠️

| 红线 | 说明 | 怎么办 |
|------|------|--------|
| 不编造经营指标 | 营收、利润、漏损率、项目数等必须有数据出处 | 缺失时直接说"待补充"，由你确认后再补 |
| 不跨领导混写 | 龚董与方琳的版式、句式、用词不同源 | 每次明确指定"按 XXX 风格写" |
| 不发对外公文 | 涉密/敏感内容只能内部使用 | 走 OA 流程印发，不通过我外发 |
| 不替代法规检索 | 涉及具体法规条文请走专业法律工具 | 我只做"风格化表述"，合规审校不在我能力圈 |
| 不删任何文件 | 归档永远"只复制不删除" | 误归档可还原，原始素材零风险 |
| 不调未授权域 | 知识库写入仅限 `authorized_domains` 内的团队/空间 | 无权访问会直接告知，不伪造检索结果 |

## 3. 怎么开始（3 步走）

### Step 1 · 确认专家已加载

在 WorkBuddy 对话框中输入 `/agents` 或查看专家列表，应当能看到「文秘专员」。如果看不到：
- 联系管理员推送本插件（见分发包 README 第 II 节"管理员统一推送"）
- 或自行 `/plugin install water-office-writer@szwater-experts`

### Step 2 · 把任务给我（5 要素清单）

派活前请先想清楚以下五点，越齐越好：

| 要素 | 问自己 | 示例 |
|------|--------|------|
| **谁说** | 哪位领导风格？ | 龚董 / 方琳总 / 新领导（需先建模） |
| **什么文种** | 半年总结 / 年终报告 / 致辞 / 呈报？ | 半年总结 |
| **哪段时间** | 覆盖什么区间？ | 2026 年 1-6 月 |
| **写什么** | 重点事项、亮点数据、要部署的工作 | 漏损率、AI 赋能、市场化转型 |
| **要不要查历史** | 是否需要从知识库拉素材？ | 是 / 否 |

### Step 3 · 看产物、读自检、提反馈

我交付时会同时给你三样东西：
1. **Markdown 源稿**（`.md`，便于你读、改）
2. **公文版式 Word**（`.docx`，可直接报送）
3. **自检清单**（逐项核验字体/字号/缩进/落款，标注数据出处与"待补充"项）

请重点看自检清单里标"⚠️ 待确认"的部分——那些是我必须由你把关的事实点。

## 4. 怎么给我派活（5 个典型 prompt 模板）

直接复制下面任一模板，把 `【】` 占位符替换掉即可。

### 模板 A · 半年总结（龚董风格）

```
请按龚董（龚利民）的风格，写一份【集团 2026 年上半年工作总结】。
覆盖范围：2026 年 1 月至 6 月。
重点：① 营收/利润/漏损率/渗透率等核心指标；② AI 赋能、新质生产力、市场化转型；
③ 党的建设与廉政；④ 下半年 7 个方向的工作部署。
如需引用历史表述，请从乐享知识库检索"龚利民 2025 年半年总结"做参考。
```

### 模板 B · 年终报告（方琳总风格）

```
按方琳总（方琳）的风格，写一份【集团 2025 年度工作报告（年终版）】。
结构用"六个坚持 + 12 字四部分部署"。
重点：经营指标、资本运作（REITs/科创债）、市值管理、对标世界一流。
要求正文 16pt 仿宋_GB2312、首行缩进 1.13cm（方琳总风格档参数）。
```

### 模板 C · 会议致辞（致辞模板，对外）

```
按龚董风格，起草一份在【广东省人工智能与机器人产业大会】上的致辞。
要点：① 点名来宾；② 集团在 AI 赋能水务的实践；
③ 行业倡议；④ 表达合作意愿。
字数 1000 字左右，致辞文风（题注式、带署名行、无页码）。
```

### 模板 D · 对部委呈报

```
按公文格式（--doc-type baogao），生成一份《关于深圳水务集团
2025 年度水务保障工作情况的报告》，主送：国家某部委。
要求：① 单位定位开篇；② 数据密集、客观恭敬；③ 末尾"专此报告。"；
④ 单位全称落款（不署个人姓名）。
```

### 模板 E · 素材归档

```
请把【D:/新进素材/】这一批文档归类到知识库，默认 dry-run。
要求：① 先给 plan.json 和 decisions.json 让我看；
② 不要直接动盘；③ 我确认后再加 --apply。
```

## 5. 派活前要准备什么（Pre-flight Checklist）

| 准备项 | 必要性 | 备注 |
|--------|--------|------|
| 领导 + 文种 + 重点 三件套 | 必需 | 缺一不可，硬着头皮能写但质量差 |
| 核心数据（指标/项目/时间） | 强烈推荐 | 你不给我就标"待补充" |
| 历史范文 1-2 篇做参考 | 推荐 | 让"像不像"更稳 |
| 知识库检索授权 | 看场景 | 没权直接告知，不会硬造 |
| 输出目录 | 可选 | 默认当前工作区，可在 MEMORY.md 约定 |

## 6. 输出物长什么样

```
你的工作目录/
├── 【稿名】.md               # Markdown 源稿（建议先读这版）
├── 【稿名】.docx             # 公文版式 Word（报送用这版）
└── 【稿名】_自检清单.md       # 自检报告（先看这版挑刺）
```

自检清单会包含：
- ✅ 已核验项（字体、字号、缩进、边距、落款、页码）
- ⚠️ 待确认项（数据出处、署名日期、专有名词）
- ❌ 阻塞项（缺素材、风格档案不存在、权限不足）

## 7. 常见误区与红线（避坑）

| 误区 | 后果 | 正确做法 |
|------|------|----------|
| "把两位领导风格混着用" | 落版不合规、领导一眼看出不像 | 明确指定一位 |
| "让我凭空写营收数字" | 编造数据 → 报送后被退回 | 把指标清单/财务口径先给我 |
| "让我直接覆盖原文件" | 我会拒绝，但你会浪费一轮 | 先说明"建副本"还是"原地改" |
| "把 PDF 当 Word 改" | PDF 内文本不能编辑，我只能 OCR 重建 | 给我原始 docx/md 或同意 OCR 重建 |
| "让我查张三的工资" | 涉密/隐私，我直接拒绝 | 走 HR 系统或 OA |
| "改了档案但不回归测试" | 下一次落版可能错版式 | 任何档案改动后跑 `selftest/regress.py` |

## 8. 出问题找谁

| 问题类型 | 找谁 |
|----------|------|
| 不会派活 / 输出不合预期 | 综合办数字员工项目组（项目内文档） |
| 专家未加载 / 插件报错 | 集团信息中心 / WorkBuddy 管理员 |
| 知识库检索不到 | 乐享管理员开通对应团队权限 |
| 领导风格档案不准 | 拿原文样本给项目组，重新建模 |
| 涉密/红线判定 | 综合办保密员 |
