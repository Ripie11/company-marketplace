# 公司分发包 · 公文报告统一输出目录

> 本目录是 **`zhibi-suiwen` skill 的公司级默认输出位置**，所有由集团综合办公室或各成员单位通过本 skill 生成的公文报告（`.docx` / `.md`），统一归档到本目录下，便于随分发包分发与版本管理。

## 目录约定

| 维度 | 约定 |
|------|------|
| **路径** | `company-marketplace/output/`（即仓库根 `output/`） |
| **作用** | 接收 `zhibi-suiwen` 生成的 `.md` 源稿与 `.docx` 公文 |
| **生命周期** | 跟随分发包生命周期，`git` 版本管理 |
| **访问控制** | 仓库私有（参见上级 README.md 安全章节），禁止公开发布 |

## 子目录命名建议

按 **领导 + 文档类型 + 时间** 组织，便于后续检索：

```
output/
├── 龚利民（董事长）/
│   ├── 半年工作总结/
│   │   └── 2026H1_半年工作总结_新优势新作为新突破_龚利民.docx
│   └── 致辞/
│       └── 2026MMDD_致辞_标题_龚利民.docx
├── 方琳（总裁）/
│   ├── 半年工作总结/
│   └── 年度工作总结/
└── _archive/                          # 历史归档
```

> 📌 文件命名遵循项目 `MEMORY.md` 中的 `YYYYMMDD_文档类型_清理后标题_领导.扩展名` 规范。

## 使用方式

```bash
# 落版 docx 时显式指定本目录
python <skill>/scripts/md_to_gongwen_docx.py \
  --input "output/龚利民（董事长）/半年工作总结/2026H1_半年工作总结_新优势新作为新突破_龚利民.md" \
  --output "output/龚利民（董事长）/半年工作总结/2026H1_半年工作总结_新优势新作为新突破_龚利民.docx" \
  --leader "龚利民"
```

## 与 skill 路径约定的关系

`zhibi-suiwen` 的「报告输出」路径解析优先级：

1. **用户显式指定**（最高）
2. **MEMORY.md 中「输出目录」约定** → 命中 `company-marketplace/output/`
3. **当前工作区根目录**（兜底）

> 也就是说，只要在不显式指定 `--output` 时，skill 优先向 `company-marketplace/output/` 落档。

## ⚠️ 注意事项

- **不进 git 跟踪敏感稿**：包含"内部资料"、"绝密"、"机密"等标识的草稿不得上传到本仓库；建议在本地 `.gitignore` 中按领导目录粒度排除。
- **不要把乐享知识库 ID / 用户账号等硬编码**到任何 .md/.docx 文件里，避免随分发包泄露。
- **冲突处理**：同名文件覆盖前先 `git diff`，确认差异；冲突无法调和时改用 `YYYYMMDD_v2_...` 后缀。
